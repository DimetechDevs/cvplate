# Font licences

All PDF typefaces in this folder are distributed under the SIL Open Font License 1.1 (https://openfontlicense.org), which permits embedding them in documents.

The files are static instances subset to Latin, Latin Extended, Vietnamese, Greek and Cyrillic, generated from the upstream Google Fonts sources by `scripts/build_fonts.py`. The families are Carlito, Caladea, Gelasio, Source Sans 3, Source Serif 4, EB Garamond, IBM Plex Sans, Libre Franklin and Inter.
